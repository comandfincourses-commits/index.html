# Warren Buffett Part 1: ChatGPT + Sora Prompts (37 shots)

## How it works

1. **Create the 9 characters first** in one ChatGPT chat, using `WB_Character_Bible.md`. Keep using that same chat.

2. **For each shot, Step 1 (ChatGPT image):** paste the IMAGE prompt into the same chat. It refers to the characters by name, so ChatGPT reuses their faces. Download the image.

3. **Step 2 (Sora video):** open Sora (sora.com, or Sora inside ChatGPT), upload the Step 1 image, paste the VIDEO prompt, choose **16:9 landscape, 10 seconds**, and generate. Download it as `wNN.mp4` (e.g. `w01.mp4`).

4. **Shots without characters** go straight to Sora with the VIDEO prompt (no image needed).

5. Never type real names. If Sora won't animate an image of a realistic person, use the text-only video prompt instead and send me the result. I'll check consistency.
